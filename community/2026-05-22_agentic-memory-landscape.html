💡 五、对研究的启示

Research Opportunities Identified

  1. Memory Evaluation Harness 是蓝海
    目前 LongMemEval 被引用最多，但社区认为不够。@PeterJ_Medina 展示"换个 harness 从 3.3%→31.8%"——evaluation 本身的设计空间巨大。这是你可以建立 benchmark 话语权的机会。
  2. Self-Evolving Agent 的 Memory 问题未解
    @sheriyuo 精确描述的问题正是你的方向：agent 需要 memory 作为 exploration + reflection 载体，但超长上下文下如何无损 recall 旧 trajectory？现有方案（reflexion, agentmemory）都在做"有损压缩"，理论上的无损方案尚未被提出。
  3. 从 Static Context (CLAUDE.md) 到 Dynamic Memory 的演进路径
    CLAUDE.md 144K stars 证明了静态 context 的价值，但社区明确认为这是 v1。你的研究可以定义 v2 是什么样的——self-correcting、decay-aware、contradiction-resolving 的 dynamic memory system。
  4. MeMo "Memory as a Model" 与你方向的交叉
    将 memory 从检索问题重新定义为模型训练问题。与 agentic memory 的交叉点：能否训练一个专门的 memory model 来服务 agent 的 episodic/semantic recall？
  5. 实践↔学术的桥梁机会
    agentmemory 等工程项目已在用 episodic/semantic/procedural 分层，但缺乏理论支撑。你的研究可以反向指导——什么时候该压缩？什么必须保留？decay function 怎么设计？这些工程经验可以成为你论文的 motivation 和 evaluation scenario。
