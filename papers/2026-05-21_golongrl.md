## 1) 一句话 Why-read
- **Key claim/contribution + key observation：** 首个完全开源的 long-context RLVR recipe：23K 样本覆盖 9 种 capability-oriented 任务 + TMN-Reweight 解决异构 reward 优化问题。关键发现：4B 模型用该数据 + vanilla GRPO 即超越闭源 QwenLong-L1.5 数据集；30B 模型达到 DeepSeek-R1-0528 / Qwen3-235B 可比水平。

---

## 2) CRGP 拆解 Introduction
### C — Context
- Long-context reasoning 是 LLM 核心能力之一，RLVR 已在 short-context math 上验证有效。
- QwenLong-L1.5 首次将 RLVR 扩展到 long-context，但数据集闭源且任务设计以 retrieval path 复杂度为主导。

### R — Related work
- **Long-context RL：** QwenLong-L1.5 (AEPO)，侧重 retrieval path diversity。
- **GRPO 变体：** Dr.GRPO（token-level normalization）、HA-DW（difficulty-adaptive weighting）。
- **长上下文数据：** LongBench, MRCR, Frames, CorpusQA 等 benchmark。

### G — Gap
1. 现有 long-context RL 数据同质化（偏 retrieval），缺乏 capability taxonomy 指导。
2. 异构 reward（不同任务 scale/variance 不同）导致 GRPO 梯度不平衡 — Dr.GRPO 的 token-level normalization 反而加剧跨任务 imbalance。

### P — Proposal
1. **Capability-oriented data construction**：9 种任务类型（Retrieval, Comprehension, Exhaustive Retrieval, Numerical, Structured Extraction, Matching, Ranking, Ordering, Summary），23K 样本，fully open。
2. **TMN-Reweight**：Task-level Mean Normalization（用 task-level σ 替代 per-prompt σ，消除跨任务 scale 差异）+ Difficulty-adaptive reweighting（按 smoothed pass rate 加权，α=0.8 最优）。

## 4) Experiments
### 4.1 Experimental setup
- **训练数据：** 23K（full dataset for 30B），8K subset for 4B 消融
- **模型：** Qwen3-4B-Thinking-2507, Qwen3-30B-A3B-Thinking-2507
- **框架：** verl, strictly on-policy
- **训练参数：** batch size 128, group size 16, lr 2e-6, 5 warmup steps, temperature 1.0, top-p 1.0, IcePop for train/inference mismatch
- **评测 benchmarks（6个）：** LongBench-V2, MRCR, Frames, LongBench (5 subsets), DocMath, CorpusQA
- **General capability：** MMLU-Pro, AIME24/25, GPQA-Diamond, BFCL-V4 Memory, LongMemEval

### 4.3 Analysis experiments

- **现象1：** GoLongRL 数据 + vanilla GRPO 即超越 QwenLong-L1.5 (AEPO) 的闭源数据（62.2 vs 59.4 avg）。
  **解释（作者）：** capability-oriented taxonomy 带来的任务多样性比 retrieval path 复杂度更重要。
  **【标注】** 这是个很强的信号：数据设计 > 算法创新（对 long-context 场景）。

- **现象2：** TMN-Reweight 相对 vanilla GRPO 主要在 aggregation/reasoning 任务上提升（CorpusQA +4.5, LBV2 +1.6），但在 retrieval 任务上略降（MRCR -2.0）。
  **解释（作者）：** TMN 均衡了梯度，对需要多能力协调的任务更有利；单一检索行为可能被"稀释"。
  **【标注】** 任务异构性是 long-context RL 的根本挑战 — 不同任务需要的能力本质不同，统一优化目标有 tradeoff。

- **现象3：** Difficulty-adaptive reweighting 的 α=0.8 最优；α=1.0 反而下降。
  **解释（作者）：** α 控制 task-level baseline 的混入比例；α=1.0 完全依赖 per-prompt 均值，smoothing 不足导致高方差。

- **现象4：** Long-context RL 训练**不仅不损害** general capability，反而提升 agentic memory（Memory-Rec_Sum +9.7）和 dialogue memory（LongMemEval +13.6）。
  **解释（作者）：** long-context RL 强化了模型对长距离信息的整合能力，这自然迁移到 memory-related tasks。
  **【标注】** **这是最有趣的发现** — long-context RLVR 可能是 agentic memory 能力的"免费午餐"来源。

## 5) Why it matters for our work
- **Long-context + RL 交叉点：** 直接提供了开源的 long-context RLVR recipe，可以直接复用。
- **Agentic memory 意外收益：** Table 7 明确显示 long-context RL training 显著提升 BFCL Memory 和 LongMemEval — 这对我们设计 agentic memory system 有直接启示（可能不需要专门的 memory training，long-context RL 自带 bonus）。
- **数据设计思路：** 9-type capability taxonomy 可以指导我们为 agentic tasks 设计 RL 训练数据。
- **TMN-Reweight：** 在 multi-task agentic RL 中（不同 tool 有不同 reward scale），TMN 的 task-level normalization 思路可直接迁移。

## 7) 评分解释
- **Type:** A (RL Training)
- **Relevance:** 5/5 — 直接命中 long-context reasoning + RL，且实验显示对 agentic memory 有显著正迁移。
- **Quality:** 4/5 — 完全开源（数据+代码+模型），实验覆盖 4B/30B，6 个 long-context + 7 个 general benchmark，消融充分。
- **质量分 2/2：** 开源贡献 + 扎实实验 + 跨 scale 验证。
- **Observation 分 1/2：** "capability-oriented taxonomy > retrieval path complexity" 和 "long-context RL 免费提升 memory" 是 actionable insights，但方法本身（TMN = 换个 normalization + 加 difficulty weighting）novelty 有限。
- **总分：4/5**
- **为什么不是更高分：** (1) TMN-Reweight 的 incremental gain 仅 +0.8 avg over vanilla GRPO — 数据贡献 >> 算法贡献；(2) 30B 实验只用了 vanilla GRPO（没在 30B 上验证 TMN-Reweight）；(3) 缺少与 QwenLong-L1.5 AEPO 算法的 fair comparison（用同样数据对比算法）。
