## 1) 一句话 Why-read
- **Key claim:** 在 100+ turn 的长horizon游戏中（Super Mario Land），用 PPO + 轻量CNN turn-level critic + positive-advantage filtering 可以稳定训练 VLM agent，比 GRPO/Reinforce++ 显著更好；VLM 的 pretrained knowledge 使得 RL 比 classical deep RL 有 ~2× sample efficiency 优势。
- **Key observation:** Critic-free 方法（GRPO、Reinforce++）在 long-horizon dense-reward setting 完全失败，temporal credit assignment 需要 learned critic；但 critic 不需要是大模型——一个小 CNN 就够了。

## 4) Method

### 4.1 PPO with Lightweight Turn-Level Critic
核心洞见：long-horizon dense-reward setting 中，critic-free 方法（GRPO/Reinforce++）无法做好 temporal credit assignment → 必须用 learned critic。

**关键设计:**
1. **Turn-level critic**（而非 token-level）: 直接利用环境的 dense reward signal，在 turn 粒度做 credit assignment
2. **Lightweight CNN critic**: 不需要用 VLM 做 critic（传统做法 = 几乎 2× 计算量）→ 一个小 CNN 读游戏画面即可
3. **Positive-advantage filtering**: 过滤 A < 0 的 sample，避免负优势样本导致训练不稳定

Insight: 把 value estimation 从 VLM 中解耦出来，delegating to a small module → 大幅降低 memory/compute 瓶颈

### 4.2 Interaction Protocol
- **输入**: 当前 game frame + textual prompt（最小化 scaffolding，只看当前帧）
- **Structured CoT**: `<perception>` → `<reasoning>` → `<answer>`
- **Action space**: 7 buttons (a, b, up, down, left, right, noop)，最多同时按 2 个
- **Frame skip**: 重复执行选定 action 若干帧以产生可观察效果

### 4.3 SFT Initialization (Lightweight)
- ~5000 frames from walkthrough videos × GPT-o3 生成 teacher responses
- 只注入 domain knowledge + perception，不追求 action optimality
- 比之前的 SFT-heavy 方法（需要 expert trajectories）更 scalable

### 4.4 Multi-Task RL with Auto-Curriculum
- 同时在多个 level 训练，batch 包含来自不同 level 的 trajectories
- **Auto-curriculum**: inverse trajectory weighting — 短轨迹（难关卡）获得更高采样权重 w_k ∝ 1/N_k
- 防止优化偏向容易的 level

- GRPO (outcome reward): slight improvement but stagnates

## 6) Limitations
1. **环境限制**: 只在 Super Mario Land 验证，虽有 cross-game 泛化但仍是 platformer 类游戏
2. **Turn-level critic 依赖环境 state**: CNN critic 需要 visual observation 作为 state representation — 对于非 visual 或 partially observable 环境可能需要不同设计
3. **SFT initialization 依赖强模型**: 用 GPT-o3 生成 teacher labels — 对于没有 strong teacher 的领域需要替代方案
4. **Dense reward 依赖**: reward = x-coordinate delta（超密集信号）— 稀疏 reward 环境的适用性未验证
5. **Scale**: 只在 8B 模型验证，更大模型的 scaling behavior 未知
6. **Positive-advantage filtering 的理论理解**: 论文承认这仍是 actively studied question

## 7) My Technical Take

### 核心 insight 的价值
这篇论文最有价值的不是 Odysseus 框架本身，而是 **实验性地回答了几个重要问题**:
1. GRPO/Reinforce++ 在 long-horizon 完全不行 → 这对所有做 agentic RL 的人都是重要 negative result
2. Critic 可以极度轻量化（CNN，不需要 LLM-based）→ 大幅降低 VLM RL 的工程门槛
3. VLM pretrained knowledge = strong action prior → RL 不需要从零学 perception

### Transfer to ongoing projects
- **对 agentic memory + RL**: 如果做 memory-augmented agent 的 RL training，critic 的设计可以参考这里——不需要用 LLM 做 critic，轻量模块足够
- **Turn-level vs Token-level**: 他们选择 turn-level advantage（而非 token-level）因为环境给的是 turn-level reward。对于 agentic task（tool call 粒度），这个设计选择很有启发
- **Positive-advantage filtering**: 这个 trick 在 agent RL 中也值得尝试——只学"做对了什么"而不penalize"做错了什么"
- **Auto-curriculum**: 多任务 agent training 时，inverse difficulty weighting 是一个简单有效的策略

### 与其他工作的联系
- **vs GRPO (DeepSeek-R1)**: GRPO 在 reasoning (短horizon, outcome reward) 成功，但在 long-horizon dense-reward 失败。这暗示 GRPO 的适用范围可能比人们以为的窄。
- **vs SimuRA / Self-Regulated Planning (Mingkai Deng)**: 那篇关注"何时规划"，这篇关注"如何稳定训练"——互补视角
- **vs Game-playing agents (CivBench等)**: 之前的 Civ 相关工作多是 scaffolding/prompting，Odysseus 是 RL from scratch 的路线
