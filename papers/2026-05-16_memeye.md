## 1) 一句话 Why-read
- **Key claim/contribution + key observation：** 提出 2D evaluation matrix (X=视觉证据粒度 scene→pixel, Y=记忆推理深度 atomic→evolving synthesis)，发现 13 种 memory 方法在 fine-grained visual detail preservation 和 evolving state tracking 上都严重不足 — semantic similarity ≠ temporal validity。

## 2) CRGP 拆解 Introduction
### C — Context
- VLM agents 需要跨 session 记忆视觉信息，但现有 benchmark (LoCoMo, MMRC, Mem-Gallery) 的视觉问题大多可通过 caption 回答，不能真正测试 visual evidence preservation

### R — Related work
- Long-term memory benchmarks (LoCoMo, MMRC), multimodal memory methods (MMA, M2A, MIRIX, SimpleMem), agentic memory (Reflexion, Generative Agents, MemoryOS, A-Mem)

### G — Research gap
- (1) 没有 benchmark 分离 visual granularity 和 reasoning depth 两个维度；(2) 缺乏 evolving visual state 测试；(3) 很多"视觉"问题 caption 就能解（shortcut）

### P — Proposal
- 2D framework (X1-X4 × Y1-Y3) + 8 life-scenario tasks + ablation-driven validation gates (answerability, shortcut resistance, visual necessity, reasoning structure)

## 4) Experiments
### 4.1 Experimental setup
- **任务/数据：** 8 life-scenario tasks（探索、游戏、家居、化石、实验室等）
- **模型/agent 配置：** Qwen3-VL-8B, GPT-4.1-nano, GPT-5.4-mini, Gemini-2.5-flash-lite
- **对比基线：** 13 methods = 7 text-based (FC(T), SRAG(T), Reflexion, Gen.Agents, MemOS, A-Mem, SimpleMem(T)) + 6 multimodal (FC(V), SRAG(V), MIRIX, MMA, M2A, SimpleMem(V))
- **评测指标：** MCQ Exact Match (EM, 4-rotation avg), LLM-as-a-Judge (open-ended), Cohen's κ=0.94 与人类一致

- Oracle Y-axis drop: Y1→Y2→Y3 = 0.673→0.601→0.558

### 4.3 Analysis experiments
- **现象：** Text memory 在 X3/X4 (Instance/Pixel level) 崩溃
  **解释（作者）：** Caption-Proof gain Δ=Score_V - Score_T 在 X3/X4 显著为正，text storage 丢失 instance/pixel 级信息
  **【标注】** 这直接说明 caption-only memory 是不够的，必须保留原始视觉 evidence

- **现象：** Evolving state (Y3) 让所有 retrieval-based 方法失效
  **解释（作者）：** Semantic similarity ≠ temporal validity。SRAG(V) 能 retrieve 相关 topic 但 miss latest valid state
  **【标注】** Oracle 实验显示直接给最新 valid state 即可接近 full oracle chain → 问题本质是 memory system 不能 prioritize recency over staleness

- **现象：** 两个 interacting stressors（高X + 高Y）叠加更严重
  **解释（作者）：** Fine-grained visual + evolving state 形成 compound difficulty — bottleneck 从 evidence access 转为 state selection

## 5) Why it matters for our work
- **直接提供 evaluation taxonomy**：可用 2D matrix 定位我们 memory system 的弱点
- **证实 text summary 不够**：对 memory 设计有直接启示 — 必须保留原始 visual evidence
- **Evolving state tracking 是新 challenge**：当前 RAG 靠 semantic similarity 不够，需要 temporal validity / recency-aware selection
- **Benchmark 可直接复用**：8 tasks, 12 cells, 开源

## 6) Actionable next step
- [ ] Clone MemEye benchmark 跑一遍我们的 memory system，定位在 X×Y matrix 中的弱点
- [ ] 设计 hybrid storage: image evidence + structured state record + recency-aware retrieval
- [ ] 引入 temporal validity signal — 不只按 semantic similarity rank，还要 penalize stale evidence

## 7) 评分解释
- **质量分 1.8/2：** 实验设计严谨 (validation gates, 4-rotation MCQ, human agreement κ=0.94)，13 方法×4 backbone 覆盖全面
- **Observation 分 1.8/2：** "visual granularity vs reasoning depth" 的 2D decomposition 是强 insight；semantic similarity ≠ temporal validity 诊断有价值
- **总分 4/5：** 基础 1 + 质量 1.8 + Observation 1.8 ≈ 4
