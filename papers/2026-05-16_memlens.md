## 1) 一句话 Why-read
- **Key claim/contribution + key observation：** 首个系统性对比 long-context LVLMs vs memory-augmented agents 在多模态多轮对话记忆任务上的 benchmark；核心发现：前者随 context 增长退化，后者压缩时丢失视觉保真度，multi-session reasoning 把所有系统压在 30% 以下。

## 2) CRGP 拆解 Introduction
### C — Context
- LVLMs 需要记忆能力处理长期多模态交互，当前两条路线：long-context LVLMs（扩展 context window）与 memory-augmented agents（Mem0, MemAgent 等）

### R — Related work
- 现有 benchmark（MMLongBench, HELMET 等）未系统对比两类方法，且缺乏真正需要多模态 evidence 的问题设计

### G — Research gap
- 没有 benchmark 能同时：(1) 要求视觉证据而非纯文本可解 (2) 跨多 session 推理 (3) 公平对比 long-context vs agent 两种范式

### P — Proposal
- MEMLENS：789 questions × 5 memory abilities × 4 context lengths (32K-256K)，cross-modal token counting scheme，image-ablation 验证视觉必要性

## 3) Figure 区

## 4) Experiments
### 4.1 Experimental setup
- **任务/数据：** 5 memory abilities — IE (Information Extraction), MSR (Multi-Session Reasoning), TR (Temporal Reasoning), KU (Knowledge Update), AR (Answer Refusal)
- **模型/agent 配置：** 27 LVLMs (GPT-4o, GPT-4.1, o3, o4-mini, Claude Sonnet/Opus 4, Gemini 2.5/3 Pro/Flash, Kimi K2.5, Qwen2.5-VL-7B/72B, Qwen3-VL-2B/4B/8B/30B/235B 等) + 7 memory agents (M3-Agent, M2A, M3C, Memory-T1, Mem0, MemOS, MemAgent-7B)
- **对比基线：** Agent evaluation 在 195-question stratified subset (61 IE / 35 MSR / 48 TR / 29 KU / 22 AR)
- **评测指标：** SubEM (Substring Exact Match), F1, LLM-as-Judge, Calibration score

### 4.2 Main result table
| Dimension | Long-context LVLMs | Memory Agents | Finding |
|---|---:|---:|---|
| Short context (32K) | High (frontier) | Moderate | LVLMs > Agents |
| Long context (256K) | Degrades significantly | Length-stable | Agents catch up |
| Visual fidelity | Direct grounding ✓ | Compression loss ✗ | LVLMs >> Agents |
| Multi-session reasoning | <30% | <30% | Neither solves it |
| Image ablation (80.4% Qs) | Drops to <2% | — | Visual necessity confirmed |

### 4.3 Analysis experiments
- **现象：** Long-context LVLMs 在 32K→256K 过程中性能持续下降
  **解释（作者）：** attention dilution + 多模态 token 计数不一致导致有效 attention 被稀释
  **【标注】** Cross-modal token counting 是关键设计贡献

- **现象：** Memory agents length-stable 但视觉信息丢失
  **解释（作者）：** 存储时压缩（captioning/embedding）损失原始 pixel 信息
  **【标注】** 直接印证 visual evidence preservation 是 memory system 设计的核心挑战

- **现象：** Multi-session reasoning 把所有系统压在 30% 以下
  **解释（作者）：** 跨 session 整合信息需要 compositional reasoning，两种范式都无法有效解决

## 5) Why it matters for our work
- **直接 evaluation target**：如果我们做 agentic memory system，MEMLENS 同时测试 retrieval (IE), reasoning (MSR/TR), update (KU), 和 abstention (AR)
- **Architecture insight**：核心结论 "hybrid architectures combining long-context attention with structured multimodal retrieval" 直接指导 memory system 设计
- **Baseline zoo**：7 个 memory agent baselines 的评测结果可直接作为 comparison points
- **Visual memory gap**：明确指出当前 memory 系统在视觉记忆保持上的缺陷
