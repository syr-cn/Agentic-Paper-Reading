## 1) 一句话 Why-read
- **Key claim:** Self-distillation（用同一模型 conditioned on rich feedback 作为 self-teacher）提供 dense token-level credit assignment，在竞赛编程上超越 GRPO（LCB v6: 48.8% vs 41.2%），4× 更快收敛，3× 更短生成。
- **Key observation:** Self-teacher retrospection 是 emergent with scale 的能力 —— SDPO 的优势随模型规模增长，意味着 frontier models 受益更大。

## 2) CRGP 拆解 Introduction
### C — Context
- LLM 通过 RL 做 post-training 在 verifiable domains（code, math）已成主流
- 现有 RLVR 方法（GRPO 等）仅使用 sparse scalar rewards（binary pass/fail）→ 严重的 **credit-assignment bottleneck**
- 当一个 batch 内所有尝试全部失败时，gradient 为零，尽管环境提供了丰富的诊断信息

### R — Related work
- GRPO / PPO / REINFORCE for LLM RL（Shao et al., 2024; Schulman et al., 2017）
- Knowledge distillation from stronger teacher（Hinton et al., 2015）
- Multi-turn self-correction / refinement（Madaan et al., 2023; Shinn et al., 2023）
- Process reward models for dense credit（Lightman et al., 2023）— 需要额外训练

### G — Research gap
1. 现有 RLVR 无视 rich textual feedback（compiler errors, test failures, judge evaluations）
2. 没有方法能在不引入外部 teacher/reward model 的情况下将 rich feedback 转为 dense learning signal
3. 全部 rollouts 失败时 GRPO 梯度为零 — 从失败中学习的能力完全缺失

### P — Proposal
**SDPO** = Self-Distillation Policy Optimization：
- **Student:** π_θ(·|x) 生成 attempts
- **Self-teacher:** π_θ(·|x, f) = 同一模型 conditioned on feedback f
- Loss: minimize KL(student ∥ stopgrad(self-teacher)) at each token position → dense logit-level advantages，无需任何外部模型

## 4) Experiments

### 4.1 Experimental setup
- **Models:** Qwen3-8B (default), Qwen3-0.6B/1.7B/4B (scaling study), Olmo3-7B-Instruct
- **Tasks (scalar feedback only):** Chemistry, Physics, Biology, Materials Science (SciKnowEval L3), Tool Use (ToolAlpaca)
- **Tasks (rich feedback):** LiveCodeBench v6 (131 problems, Feb-May 2025)
- **Baselines:** Improved GRPO (asymmetric clipping, unbiased normalization, off-policy correction)
- **Infrastructure:** 4× NVIDIA GH200 GPUs, verl library
- **Metrics:** avg@16 (reasoning), avg@4 (LCB), discovery@k (test-time)

### 4.2 Main result table

**LiveCodeBench v6 (rich feedback):**

| Method | Final Accuracy |
|--------|---------------|
| GRPO | 41.2% |
| **SDPO** | **48.8%** |
| Claude Sonnet 4 | 40.5% |
| Claude Opus 4 | 39.7% |

**Science/Tool Use (scalar feedback, 5h training):**

| Method | discovery@2750 |

### 4.3 Analysis experiments

- **现象：** SDPO 优势随 model size 增长（0.6B: ≈ GRPO; 8B: >> GRPO）
  **解释（作者）：** Self-teacher retrospection 是 emergent capability，依赖 in-context learning 能力
  **【标注】** 这预测 SDPO 在 frontier models 上受益更大 — 值得在 >30B 模型上验证

- **现象：** SDPO 生成长度平均 3× shorter（Chemistry 最高达 7×）
  **解释（作者）：** Dense credit assignment 产生 sparse token-level advantages → filler tokens 得不到 reward → 模型学会 concise reasoning
  **【标注】** 挑战了 "长 CoT 是必须的" 叙事；verbose reasoning 可能部分是 sparse reward 的训练 artifact

- **现象：** 即使全部 rollouts 失败，SDPO 仍有学习信号
  **解释（作者）：** Rich feedback 经 self-teacher 仍可提供 per-token guidance（而 GRPO 梯度为零）

## 5) Why it matters for our work
- **OPD 范式验证：** SDPO 的核心 = "compress feedback into weights via self-teaching" — 与 episodic memory distillation 思路一致
- **Agent tool-use 直接可用：** 任何产生 structured error messages 的 tool（compiler, API errors）都可作为 rich feedback f
- **Efficiency 双重收益：** 4× 更快训练 + 3× 更短推理 = 降低 agent 的 compute cost
- **Test-time self-distillation：** 提供了 multi-turn retry 的 principled alternative，不受 context window 限制
