## 1) 一句话 Why-read
- **Key claim/contribution + key observation：** 将 OPSD 作为 sigmoid-gated auxiliary loss 加到 GRPO 上，解决了 naive RL+Distillation 在 multi-turn 场景下的 instability 问题；Qwen 系列跨 3 个 scale 在 3 个 benchmark 全面超越 GRPO (+9.4% ALFWorld, +7.0% Search-QA, +10.2% WebShop-Acc)。

## 2) CRGP 拆解 Introduction
### C — Context
- RL (GRPO) 做 agent post-training 只有 trajectory-level sparse reward；OPSD 提供 dense token-level guidance（teacher = 同一模型 + privileged context/skills）

### R — Related work
- RLSD, Skill-SD, pure OPSD, GRPO variants

### G — Research gap
- (1) Multi-turn OPSD Instability: student drift → teacher guidance 也不稳定，compounding error；(2) Asymmetric Trust: privileged skill context 并不完美，negative teacher rejection 可能是 skill retrieval 错误而非 student 行为错误

### P — Proposal
- SDAR: L = L_GRPO + λ·L_SDAR，其中 L_SDAR 通过 sigmoid gate g_t = σ(β·Δ_t) 控制 teacher signal 的采纳强度——正 gap 放大蒸馏，负 gap 自动 attenuate

## 4) Experiments
### 4.1 Experimental setup
- **任务/数据：** ALFWorld（embodied agent），WebShop（web navigation），Search-QA（multi-hop search）
- **模型/agent 配置：** Qwen2.5-3B, Qwen2.5-7B, Qwen3-1.7B
- **对比基线：** GRPO, GRPO+OPSD, Skill-SD, RLSD
- **评测指标：** Task success rate / accuracy

### 4.2 Main result table
| Method | ALFWorld | Search-QA | WebShop-Score | WebShop-Acc |
|---|---:|---:|---:|---:|
| GRPO (7B) | 81.2 | 42.0 | 80.9 | 72.6 |
| GRPO+OPSD | 80.4 | 47.0 | 86.8 | 76.5 |
| Skill-SD | 85.1 | 47.8 | 86.1 | 76.5 |
| RLSD | 82.0 | 49.0 | 87.4 | 77.3 |
| **SDAR (7B)** | **85.9** | **49.0** | **89.4** | **82.8** |

Cross-scale improvements over GRPO:
- ALFWorld: **+9.4%** (avg across scales)
- Search-QA: **+7.0%**
- WebShop-Acc: **+10.2%**

### 4.3 Analysis experiments
- **现象：** Naive OPSD 在 multi-turn 场景 unstable，Search-QA 上甚至可能崩溃
  **解释（作者）：** Compounding multi-turn instability + teacher on OOD prefix 不可靠
  **【标注】** 这是直接 motivation — OPSD 好但不能直接用

- **现象：** Skill retrieval strategy 影响大 — KM: 82.8 vs Random: 73.6 vs Full: 78.1
  **解释（作者）：** K-Means clustering 选最优 skill subset 作为 privileged context 比全给或随机好
  **【标注】** 说明 teacher quality gating 不只在 token level，skill selection 本身也很关键

- **现象：** Gradient bounded by β/4，训练过程稳定
  **解释（作者）：** Sigmoid gate 的数学性质保证 gradient 不会因为 teacher noise 爆炸

## 5) Why it matters for our work
- **直接适用**：任何 multi-turn agent training pipeline 都可以 plug-in SDAR 的 gated distillation
- **Skill library + privileged context** 的思路与 RewardHarness 的 tools/skills library 异曲同工
- **Gate 机制可推广**：到 multi-modal agent、更长 horizon task
- **是我们组的工作**：直接可内部跟进、复现、扩展
