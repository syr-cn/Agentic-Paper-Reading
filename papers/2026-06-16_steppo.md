## 1) 一句话 Why-read
- **Key claim/contribution + key observation：** 指出 token-level MDP 与 agent step-level 决策之间存在**粒度错配**，提出 StepPO 将整个 interaction step 作为 MDP 基本单元，统一 step-level trajectory representation + credit assignment (GAE) + importance sampling，在 multi-hop QA/ALFWorld/WebShop 上一致优于 GRPO/PPO/RLOO 等。

## 2) CRGP 拆解 Introduction
### C — Context
- Agentic RL 成为 LLM agent post-training 的核心范式（RLHF/RLVR）。
- 现有 RL 算法（PPO, GRPO, Reinforce++）follow token-centric paradigm：每个 token 是 action，每个新 token 诱导 state transition。

### R — Related work
- **Token-level methods**: PPO, GRPO, Reinforce++, RLOO, GSPO — 全部在 token 粒度建模。
- **Step-aware partial**: GiGPO — 用 step-level trajectory 但 credit 仍在 trajectory 粒度。
- **Framework**: Agent-R1 (同组前作) — agentic RL training framework on veRL。

### G — Research gap
1. **粒度错配 (Granularity Mismatch)**: Token-level MDP 假设每个 token 独立诱导环境 transition，但实际上环境只在一个完整 action（think + tool-call）执行完后才转移。
2. 在 token-level 做 GAE/IS 时，observation tokens（环境返回）也被当作 "action" 优化，但它们本不该是策略控制的。
3. Token-level IS ratio 在长 action 中会系统性极端化（ratio 连乘），导致梯度不稳定。

### P — Proposal
- **Step-Level MDP**: state = interaction history, action = 完整的一个 agent response (think + tool-call)。环境 transition 只在完整 action 执行后发生。
- **Step-Level Trajectory Representation**: 每个 replay record 对齐一个 MDP transition（state tokens, action tokens, reward）。
- **Step-Level GAE**: TD residual 在 step 边界计算，advantage broadcast 回 step 内所有 valid tokens。
- **Step-Level IS**: 用 token ratio 的 **geometric mean**（长度归一化）作为 step-level importance ratio，避免长 action 的 ratio explosion。

## 4) Experiments
### 4.1 Experimental setup
- **任务/数据:** 4 类 agentic tasks:
  - Multi-hop QA: HotpotQA (in-domain), 2Wiki, MuSiQue (out-of-domain)
  - Academic Paper Search: RealResearchQuery
  - Embodied: ALFWorld (seen/unseen)
  - Web Navigation: WebShop (score + success rate)
- **模型:** Qwen3-1.7B, Qwen3-4B-Instruct-2507
- **对比基线:** PPO (token/token), Reinforce++ (token/token), GRPO (token/traj), RLOO (token/traj), GSPO (token/traj), GiGPO (step/traj)
- **评测指标:** Accuracy/F1, Win Rate, Task Score, Success Rate
- **训练:** Agent-R1 framework on veRL, 8×H100, lr=1e-6 (actor), γ=0.99, λ=1.0, KL coeff=0.001

### 4.3 Analysis experiments

- **现象：** 移除 step-level GAE 后，长 horizon 任务（ALFWorld, WebShop）下降更显著。
  **解释（作者）：** Step-level credit assignment 对长 horizon 任务更关键——token-level GAE 在长序列中信号稀释严重。
  **【标注】** 这与 APPO 的 future-aware advantage 动机一致——都在解决"远距离 credit 归因"问题，只是粒度不同。

- **现象：** 移除 step-level IS 后性能下降，尤其对 WebShop（action 较长）。
  **解释（作者）：** 长 action 的 token-level ratio 连乘导致 extreme values，geometric mean 归一化能稳定更新。
  **【标注】** 工程上优雅的解决方案，比 APPO 的 clip 更 principled。

- **现象：** Training dynamics 显示 StepPO 的 critic loss 始终低于 PPO，同时 reward 更高。
  **解释（作者）：** Step-level value estimation 更准确（不需要对每个 token 估 value，只在 step 边界估值），导致 critic 更稳定、actor 更新更有效。

- **现象：** Step-wise difficulty analysis（ALFWorld）显示 StepPO 对"难 step"的提升最大。
  **解释（作者）：** Step-level credit 让模型能精确识别哪个 step 出了问题并加以改进，而 token/traj level 的信号太模糊。

## 5) Why it matters for our work
- **Step-level MDP 是 agent training 的正确抽象层级**。对 memory-augmented agent，一个 "step" 可能是"查询记忆→生成回答"或"写入记忆→确认"。Step-level credit 能帮助模型学习"何时该查记忆"这类 strategic decision。
- Agent-R1 框架（同组前作）已成为 agentic RL 的标准 codebase 之一，StepPO 的改进可直接 plug-in。
- **与 APPO 的互补**: StepPO 做 step-level alignment（coarse），APPO 做 within-step decision point identification（fine）。两者结合 = step-level MDP + within-step branching at high-BS points。
- 陈恩红/刘淇组（USTC 认知智能）在 agentic RL 方向有持续产出（Agent-R1 → StepPO → Claw-R1），值得 follow。

## 7) 评分解释
- **质量分 1.5/2：** 实验覆盖 4 类 agentic task，ablation 清晰（GAE + IS 两组件），training dynamics + step-wise difficulty 分析有深度。但模型只用到 4B（Qwen3-4B），缺少更大模型的 scaling 验证；benchmark 数量（4 tasks）少于 APPO（13 tasks）。
- **Observation 分 1.5/2：** "Granularity mismatch" 观察简洁有力，geometric mean IS ratio 是 elegant 的工程解法。但 core idea（step-level MDP）相对直觉——"agent 按 step 行动，那就按 step 训练"不算 surprising insight。GiGPO 已经做了 step-level trajectory，StepPO 的增量是加了 step-level GAE 和 IS。
- **总分 4/5**
- **为什么不是更高分：** (1) Idea 虽正确但 incremental——GiGPO (step/traj) 到 StepPO (step/step) 的跨度有限；(2) 只用 1.7B 和 4B 模型，缺 7B+ 的 scaling evidence；(3) 无 DeepSearch/GAIA 等 hard benchmark，难以判断在更复杂 agent 场景下的泛化性。
