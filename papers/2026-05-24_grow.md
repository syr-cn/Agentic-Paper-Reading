## 1) 一句话 Why-read
- **Key claim:** 通过将 rollout trajectory 分解为 state-action samples 并在 group 内计算 relative advantage，可以让 GRPO 在 open-world multi-turn 任务中有效工作（解决 full-trajectory GRPO 的 context 过长 + noise 问题）。
- **Key observation:** 分解后的目标函数 J = Cγ·J_traj + J_step，其中 J_traj 保留 trajectory-level preference，J_step 在成功轨迹内部做 temporal credit assignment（越靠近成功时刻权重越大）。Critic-free 也能做 step-level credit。

## 2) CRGP 拆解 Introduction

### C — Context
- VLM agent 在 open-world (Minecraft) 中需要 multi-turn visual perception + action execution
- 现有方法依赖 SFT (expert demonstrations)，而 GRPO 是 LLM RL 的主流算法

### R — Related work
- GRPO for multi-turn: AgentGym-RL, InquireMobile, ColorAgent, AGENTRL — 但都保持 trajectory-level formulation
- Minecraft agents: VPT → STEVE-1 → ROCKET-1 → JARVIS-VLA → Game-TARS → MAIN-VLA
- 大多依赖 imitation learning，RL 方法 underexplored

### G — Research gap
- Standard GRPO 需要 full trajectories as training samples → open-world 任务中 context 过长 + 噪声大
- Full-trajectory comparison 在长交互序列中 signal-to-noise 太低
- 没有人成功将 GRPO 适配到 open-world VLM agent 的 multi-turn RL

### P — Proposal
- **Trajectory decomposition**: 将 rollout 分解为 state-action pairs
- **Discounted reward propagation**: r_{i,t} = γ^(H-t) · R(τ_i) 反向传播 sparse reward
- **Group-relative advantage** 在 state-action samples 间计算：A = (r - μ) / σ
- Surrogate analysis 证明目标函数仍有效

## 4) Method

### 4.1 Trajectory Decomposition
- G 个 parallel environments 收集 {τ_i}，每条 τ = {(s₁,a₁),...,(s_H,a_H)}
- 分解为独立 state-action samples: G_s = {(s_{i,t}, a_{i,t}, r_{i,t})}
- Reward propagation: **r_{i,t} = γ^(H_i - t) · R(τ_i)**
  - R(τ) ∈ {0,1} (sparse binary: success/fail)
  - 越靠近 task completion 的 step 获得越强信号

### 4.2 Policy Optimization
- Advantage: A_{i,t} = (r_{i,t} - μ) / σ, 其中 μ,σ 在同一 rollout group 所有 state-action samples 上计算
- PPO-clip objective: J = E[ min(ρ·A, clip(ρ, 1-ε, 1+ε)·A) ]
- 关键区别：grouped samples conditioned on **different local states** (不是 identical prompt)

### 4.3 Surrogate Analysis (核心理论贡献)
假设 H_i ≈ H (trajectory length 近似恒定)，则：
- μ ≈ Cγ · S, 其中 Cγ = (1-γ^H) / (H(1-γ)), S = avg trajectory return
- 目标函数分解: **J = Cγ · J_traj + J_step**
  - **J_traj**: ρ_{i,t} · (R(τ_i) - S) → trajectory-level relative preference (成功vs失败)
  - **J_step**: ρ_{i,t} · (γ^(H-t) - Cγ) · R(τ_i) → 只对成功轨迹有效，强化靠近成功时刻的决策
- 意义：即使 samples 来自不同 state，GRPO 的 relative optimization signal 仍然被保留

### 4.4 Cold-Start: SFT Initialization
- 3M state-action samples 初始化 VLM agent (Qwen2-VL-7B-Instruct)
- 8×H200 GPUs, ~3 days

## 5) Experiments & Evidence

### Main Results (Table 1, 800+ Minecraft tasks)

| Model | Embodied ASR | GUI ASR | Combat ASR |
|-------|:---:|:---:|:---:|
| VPT (248M) | 6.0 | 0.8 | 3.6 |
| JARVIS-VLA (7B) | 30.0 | 25.1 | 18.5 |
| Game-TARS (7B) | 50.4 | 39.1 | 38.1 |
| MAIN-VLA (7B) | 32.8 | 34.4 | 39.2 |
| **GROW (7B)** | **59.6** | **68.4** | **49.0** |

**Δ vs prev SOTA**: Embodied +9.2pp, GUI +29.3pp(!), Combat +9.8pp

### Steps Efficiency
- Embodied: 263→128 (2× faster)
- GUI: 291→248
- Combat: 248→172

### Generalization (Table 2)
| Setting | Embodied | GUI | Combat |
|---------|:---:|:---:|:---:|
| RL-Trained (before→after) | 35.0→90.0 | 10.0→92.5 | 45.0→85.0 |
| RL-Unseen (before→after) | 41.9→59.2 | 21.3→68.2 | 19.8→47.5 |

Strong generalization to unseen tasks → 学到 reusable interaction skills

### Ablation: GROW vs PPO (Table 3)
| Method | Embodied ASR | GUI ASR | Combat ASR |
|--------|:---:|:---:|:---:|
| PPO (γ=0.995) | 58.2 | 43.9 | 45.4 |
| GROW (γ=0.995) | **59.6** | **68.4** | **49.0** |

GROW 在 GUI tasks 上大幅优于 PPO (+24.5pp)

### Ablation: Discount Factor γ
- γ=0.9: 短任务好（抑制无关 early steps），长任务差（credit 传不远）
- γ=0.995: 长任务最优，但对短任务略有 trade-off
- 启发：不同 task type 可能需要 adaptive γ

## 6) Limitations
1. **Only atomic tasks**: 没有 memory module — 论文明确承认 "For long-horizon tasks requiring memory, future work will explore summarizing history after several steps"
2. **Sparse binary reward**: 只有 success/fail，没有 intermediate reward signal
3. **Surrogate analysis 假设较强**: H_i ≈ H 在真实环境中不总是成立
4. **环境限制**: 只在 Minecraft 验证
5. **γ 是全局超参**: 没有 per-task 或 per-step adaptive discount

## 7) My Technical Take

### 核心价值
GROW 证明了一个重要的 recipe：**在 critic-free GRPO 框架下，通过 trajectory decomposition + temporal discounting，可以实现 step-level credit assignment**。这比 Odysseus 的方案（需要额外 CNN critic）更轻量。

### 与 Odysseus 的对比与互补

| 维度 | Odysseus | GROW |
|------|----------|------|
| Credit Assignment | Learned CNN critic | Temporal discounting (critic-free) |
| 环境 | Super Mario Land (dense reward) | Minecraft (sparse binary reward) |
| Horizon | 100+ turns (single level) | Variable (数十步) |
| Base algorithm | PPO | GRPO-adapted |
| Context handling | 只看当前帧 | Trajectory decomposition |
| Memory | 无 | 无（明确是 future work） |

**关键互补点**：
- Odysseus 证明 dense reward + critic 最稳定 → 适合 long-horizon single-objective
- GROW 证明 sparse reward + decomposition 也能工作 → 适合 multi-task open-world
- 两者都缺 memory → **memory-augmented agent RL** 是 natural next step

### Transfer to ongoing projects
1. **GROW 的 decomposition 可以解决 Odysseus 发现的 GRPO 失败问题**: 如果不想训 critic，用 GROW 式 decomposition 让 GRPO 在 100+ turn 重新 viable
2. **Hybrid approach**: Lightweight CNN critic (Odysseus) + group-relative advantage (GROW) = better credit assignment
3. **Memory as state**: 如果 agent 有 memory module，state s_t 可以包含 memory summary → decomposition 后每个 (s_t, a_t) 自带历史信息 → 解决 GROW "lacking memory" 的问题
4. **Adaptive γ**: 不同类型决策（exploration vs exploitation）使用不同 discount → per-decision-type credit shaping
