## What They Built

一个 **2945 bytes** 的完整 WebAssembly 解释器，塞进单个 QR code。它是一个 static x86-64 Linux ELF 可执行文件，零依赖。实现了完整的 Lime1 Wasm feature set + WASI，能跑真实程序：
- Rust guessing game（cross-compiled to Wasm）
- QuickJS（完整 JS REPL）
- 通过 Wasm spec tests

QR code 最大容量 2953 bytes — 他只剩 8 bytes 余量！

## Key Technical Techniques

### 1. ELF 极限瘦身（~200 byte baseline）
- 自定义 linker script 合并所有 sections 为一个 segment
- `strip --strip-section-headers` 移除 section headers
- 无 libc — 直接 Linux syscall ABI（23 bytes 的 `_start`）
- x86 CISC `rep` 指令实现 memcpy/memset/strlen 仅 2 bytes each

### 2. CRC32 硬件指令做 Import Resolution
- 不存 import name strings，用 x86 硬件 CRC32 指令
- Hash 前 8 bytes + length → 对 closed WASIp1 接口 collision-free
- 分离 key/value arrays 启用 `repne scasw` 做 lookup

### 3. Single-Pass 执行（无预解析）
- 维护 `break_level` 整数替代预计算 jump targets
- 非零时指令只 parse 不执行，遇 block exit 递减
- 牺牲性能换代码大小（QuickJS 有明显卡顿，但能跑）

### 4. Register Globals
- GCC `register ... asm("r12")` 让 hot variables 常驻 CPU 寄存器
- 节省 ~500 bytes

### 5. Self-Modifying Code
- Runtime patch x86 指令字节替代 branching — 原始 JIT 思路
- 用于 comparisons (setcc variants)、float rounding modes
- Overlapping branches for 32/64-bit REX prefix variants

### 6. x86 奇技淫巧
- **Parity flag (PF)** 区分 min/max 操作
- **x87 FPU** 80-bit long doubles 避免 i64→float double-rounding
- `lodsl`/`stosq` 做 WASI 结构体转换

### 7. Demoscene 级压缩（~40% reduction）
- 自制 Crinkler-like packer for 64-bit Linux
- Arithmetic coding + linear context mixing + brute-forced static models
- 8 MiB hash table + CRC32 + E8 transform + bit-granularity
- 将 ~4500 byte 解释器压到 2945 bytes 以内
