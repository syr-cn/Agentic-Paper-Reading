## 1) 一句话 Why-read
- **Key claim/contribution + key observation：** 标准 agent SFT 掩码 tool responses 造成 **supervision blind spot**——模型永远不被训练去整合跨 turn 的散落证据。ACC 把 multi-turn agent trajectories "编译"成单 turn long-context QA，让 long-range dependency 的监督信号直达。+18.1 MRCR, +7.6 GraphWalks，与 8× 大模型持平。

---

## 2) CRGP 拆解 Introduction
### C — Context
- Agent 开发推动了对 LLM long-context reasoning 的需求——tool responses 散落在多 turn 中，需要跨 turn 整合。
- 现有 long-context training 要么靠昂贵的人工长文档，要么靠启发式合成数据。

### R — Related work
- Long-context extension：YaRN、LongRoPE、SelfExtend 等聚焦位置编码，不解决 training data 问题。
- Agent SFT：标准做法是 mask tool responses（只训 action prediction），把 tool output 当作 "given context"。
- Agent trajectory distillation：AgentTrek 等直接用 SFT 复现 trajectory，但不改变 supervision target。

### G — Research gap
- **Supervision blind spot:** 标准 agent SFT 中，证据（tool responses）被 mask 掉，模型在 forward pass 中看到但 loss 不 flow through → 不学习"整合远距离证据"。
- 缺乏 scalable 的 supervised data 让模型学习跨 turn 长距离推理。

### P — Proposal
- **Agent Context Compilation (ACC):** 把 multi-turn trajectory 编译为：`[question] + [compiled context (all tool responses concatenated)] → [answer]`
- 训练模型 directly answer without tool use，使 question ↔ evidence dependency explicit。
- 适用于任何 long-context method 作为 complementary SFT data。

## 4) Experiments
### 4.1 Experimental setup
- **任务/数据：**
  - Training: 10,802 compiled trajectories (Search: 3,369; SWE: 4,368; SQL: 3,065)；context length 2K-128K tokens
  - Eval: MRCR (Multi-Round Coreference Resolution), GraphWalks (graph traversal over extended context)
  - General: GPQA-Diamond, MMLU-Pro, AIME'25, IFEval
- **模型配置：** Qwen3-30B-A3B-Thinking; seq length 131,072; 4 epochs; cosine LR 1e-5
- **对比基线：** Qwen3-30B-A3B (base), Qwen3-235B-A22B (8× larger)
- **评测指标：** Accuracy on MRCR / GraphWalks / general benchmarks

### 4.2 Main result table
| Setting | Baseline (Qwen3-30B-A3B) | Proposed (+ ACC) | Delta |
|---|---:|---:|---:|
| MRCR | 50.19 | 68.28 | **+18.09** |
| GraphWalks | 69.91 | 77.51 | **+7.60** |
| GPQA-Diamond | 62.12 | 64.61 | +2.49 |
| MMLU-Pro | 76.38 | 77.88 | +1.50 |
| AIME'25 | 63.33 | 66.67 | +3.33 |
| IFEval | 75.08 | 73.95 | -1.13 |

对比 Qwen3-235B-A22B (8× active params)：MRCR 68.28 vs ~70, GraphWalks 77.51 vs ~78。

### 4.3 Analysis experiments
- **现象1：** ACC 训练后 attention pattern 出现 task-adaptive restructuring，在 coreference segments 上 attention mass 显著增加。
  **解释（作者）：** 显式 supervision 使模型学会了"选择性注意"策略，而非靠位置编码的隐式 locality bias。
  **【标注】：** 这是最有价值的发现——说明 long-context 能力不只是 positional encoding 的事，training supervision 才是关键。

- **现象2：** MoE 中出现 expert specialization——特定 expert 对 long-range dependency tokens 的激活显著高于其他 expert。
  **解释（作者）：** ACC 训练诱导了 expert 分工，部分 expert 专门处理远距离依赖。
  **【标注】：** 对 MoE + agent 方向有启示——如果 expert specialization 可以被引导，是否可以设计 routing loss 加速？

- **现象3：** General capabilities 几乎无负迁移（GPQA +2.49, AIME +3.33），轻微下降仅在 IFEval (-1.13)。
  **解释（作者）：** 编译后的 QA pairs 本身包含 reasoning 需求，不会覆盖通用能力。
  **【标注】：** 10K 样本就能有这种效果且无负迁移，数据效率很高。

## 5) Why it matters for our work
- **直接相关：** 我们研究 agentic memory + long-context。ACC 证明 agent trajectories 是 long-context SFT 的 **免费数据源**——不需要人工标注长文档。
- **Supervision blind spot** 是一个被忽视但重要的问题：standard agent SFT 永远不训练模型整合 tool responses 中的远距离信息。
- **启示：** 如果 memory system 能结构化存储 agent 历史经验，然后用 ACC 方式编译成训练数据 → 可以持续提升模型的 long-context reasoning。
- **MoE expert specialization** 的发现对 memory-augmented model design 也有启示。

---

## 6) Limitations & Open Questions
1. 只在 Qwen3-30B-A3B 验证，更大/更小模型的 scaling behavior 未知
2. Eval 只有 synthetic benchmarks (MRCR, GraphWalks)，缺少 real-world agent tasks
3. 编译过程假设 trajectory 中的 tool responses 是正确的——错误传播问题未讨论
4. 训练仅 4 epochs on 10K samples——更大规模数据量的效果？
5. 与 RL-based agent training (如 DelTA) 是否可以组合？

---

## 7) Transfer to ongoing projects
- **Agentic memory training data:** 可以用 memory retrieval traces 编译成 long-context QA 训练数据
- **Long-context eval:** MRCR 和 GraphWalks 可以作为 memory-augmented model 的 eval benchmark
- **Expert specialization 分析:** 可以在我们的 MoE 实验中加入类似的 expert activation 分析
